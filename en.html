Game

?

Each overtime gets 1 timeout. Team fouls reset each period and carry into overtime. A new period length takes effect at the next period, or right away if the game hasn’t started. Events are always recorded; the stats setting shows the Stats button.

Breaks and timeouts

?

The pre-game clock sounds 3 minutes before tip-off and at tip-off. The break and timeout clocks sound when they reach 0. To make all breaks the same length, give the halftime break the same value as the other breaks. Overtime is preceded by a regular break. Starting the game clock ends a running break or timeout.

Logo library

?

Logos are loaded from the logos folder in your GitHub repository, next to the page file. Add image files there (PNG, JPG, WebP or SVG) and name them after the team, for example espoon-basket.png, and the app suggests the logo automatically when the team name matches. The library works on the GitHub page, not inside Claude.

Special foul

Choose the player

?

FIBA 2026 rules: a player is automatically disqualified for two class 1 technical fouls, two flagrant fouls or one of each, and immediately for a disqualifying foul. Class 2 technical fouls and stopping fouls don’t lead to disqualification. All player fouls count as the player’s fouls and as team fouls. Head coach (C) and bench (B) technicals are charged to the head coach and aren’t team fouls; the head coach is disqualified after two C fouls or three C and B fouls combined. The abbreviations are the app’s own, not official score sheet marks. On the scoreboard, special fouls show as outlined balls: a yellow outline means a foul that counts toward disqualification, a white outline another special foul. A wrong entry can be removed with Undo or Remove foul.

Display window

Open the display window, drag it to the TV or projector and press Fullscreen. If the window doesn’t open, open this page’s link in another browser window and add #display to the end of the address. If you reload the control page, open the display window again.

Corrections

Undo reverses the latest entry. The buttons at the bottom of each team panel remove a point, timeout or foul even later on. The clock, shot clock and period can be fixed under Clock and period corrections.

Scorers and stats

When scorers are turned on in Settings, player numbers appear after each score. Pick the scorer or skip. Stats and the score sheet are under the Stats button once they’re turned on.

Break and timeout clocks

A new game starts in the pre-game phase: the pre-game clock can be set to end in a number of minutes or at a given time of day, and it sounds 3 minutes before tip-off and at tip-off. Start game moves to period 1, and the game clock is started separately when play begins. The possession arrow is available only once the game has started. A break clock starts when the period changes, and a timeout starts the timeout clock. They show on the board in place of the game clock, with the game clock shown smaller below. The buzzer sounds when time runs out. Starting the game clock ends a break or timeout. The break clock can be paused and adjusted, and the pre-game clock can be set to end at a given time of day (Starts at). While a break clock is running, Space pauses or resumes it and doesn’t start the game clock. Lengths are set in Settings.

Possession arrow

If the game clock is started for the first time and the arrow hasn’t been set, the arrow blinks until it’s set.

Log

The log saves every event with its time in this browser. If the device shuts down, the page continues from the latest situation, and the log shows what happened right before the break.
